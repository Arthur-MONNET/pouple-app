Installer Pouple sur ton Mac

Trois étapes, quelques commandes à copier-coller dans le Terminal. Pouple se compile sur ton Mac : rien n’est envoyé nulle part, et le code que tu lances est celui que tu peux lire.

0/3 étapes faites

Pouple fonctionne uniquement sur macOS 14 ou plus récent. Tu peux lire la page, mais l’installation se fait depuis un Mac.

Étape 1

Vérifie ce qu’il te manque2 min

Colle cette commande : elle liste les outils nécessaires et te dit lesquels sont déjà là (✓) ou à installer (✗).

Terminal
printf '%s\n' \
  "$(xcode-select -p >/dev/null 2>&1 && echo '✓ Xcode CLT' || echo '✗ Xcode CLT')" \
  "$(command -v go >/dev/null && echo "✓ Go $(go env GOVERSION)" || echo '✗ Go')" \
  "$(command -v node >/dev/null && echo "✓ Node $(node -v)" || echo '✗ Node')" \
  "$(command -v pnpm >/dev/null && echo "✓ pnpm $(pnpm -v)" || echo '✗ pnpm')"
✓ Xcode CLT
✓ Go go1.27.3
✓ Node v24.1.0
✗ pnpm   ← celui-ci est à installer

Il faut : les outils de ligne de commande Xcode, Go 1.27.3+, Node.js 22.12+ et pnpm 10. Tout est ✓ ? Passe à l’étape suivante.

Installer ce qui manque
brew install go node pnpm@10
export PATH="$(brew --prefix pnpm@10)/bin:$PATH"

Installe d’abord Homebrew (le gestionnaire de paquets de référence sur Mac), puis reviens à l’onglet précédent.

Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Il manque les outils Xcode ?

Cette commande ouvre une fenêtre d’installation de macOS (quelques minutes, sans compte Apple). Relance ensuite la vérification.

Terminal
xcode-select --install
Étape 2

Installe Pouplequelques minutes de compilation

Une seule commande : elle télécharge le code, le compile, installe l’app dans ~/Applications et la lance.

Terminal
git clone https://github.com/Arthur-MONNET/pouple-app.git && cd pouple-app && bash scripts/install-local.sh

Laisse la fenêtre ouverte jusqu’à ce que Pouple se lance tout seul. Si tu avais déjà une copie ouverte, quitte-la d’abord.

Tu utilises NVM ?

Après le git clone, place-toi dans le dossier et laisse NVM choisir la bonne version de Node avant de lancer le script.

Terminal
git clone https://github.com/Arthur-MONNET/pouple-app.git && cd pouple-app
nvm install && npm install --global pnpm@10
bash scripts/install-local.sh
Pourquoi compiler sur mon Mac ?

Il n’existe pas encore de version signée par Apple. Compiler toi-même évite l’avertissement de sécurité de macOS et te garantit que l’app correspond au code publié. Une version prête à télécharger arrivera plus tard.

Une erreur s’affiche ?

Le script dit précisément ce qui manque. Les plus fréquents :

« Install the Xcode Command Line Tools » — lance xcode-select --install, puis recommence.

« Node.js 22.12 or later is required » — installe Node avec brew install node (ou nvm install).

« pnpm 10 is required » — lance npm install --global pnpm@10.

« Quit Pouple from its menu » — quitte Pouple (icône dans la barre de menus, puis Quitter) et relance la commande.

Étape 3

Connecte Slack et Codex3 min

Pouple s’ouvre et te guide. Tu n’as rien à configurer à la main : à chaque étape, il te montre qui est connecté pour que tu vérifies que c’est le bon compte.

  1. SlackCrée l’app SlackUn clic ouvre Slack avec les bonnes permissions. Colle le jeton qu’il te donne. Selon ton espace, un administrateur peut devoir approuver.
  2. CodexConnecte ChatGPTPouple télécharge Codex si besoin. Connecte-toi dans ton navigateur : Pouple a sa propre connexion et ne touche pas à la tienne.
  3. ProjetsChoisis ton dossierIndique le dossier qui contient tes projets. Codex le lit en lecture seule ; rien n’est modifié sans ton accord.
Facultatif : réagir à l’instant

Dans l’étape Slack, tu peux ajouter un jeton d’application (xapp-) : Pouple réagit alors dès qu’un message arrive, au lieu de vérifier régulièrement. Tu peux l’ajouter plus tard.

Et ensuite

Pouple travaille, tu décides

Une bulle apparaît dans un coin de ton écran quand quelqu’un te demande quelque chose. Elle reste discrète ; tu peux la déplacer, la masquer ou arrêter Codex à tout moment depuis l’icône de la barre de menus.

Mettre à jour Pouple

Quitte Pouple, puis, depuis le dossier pouple-app :

Terminal
cd pouple-app && git pull --ff-only && bash scripts/install-local.sh

Ton jeton Slack reste dans le trousseau de ton Mac. Codex utilise une connexion réservée à Pouple. GitHub sert au téléchargement de Codex et à la vérification des mises à jour.
