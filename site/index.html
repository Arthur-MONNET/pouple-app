Installer depuis les sources

Il te faut les outils de ligne de commande Xcode, Go 1.27.3 ou plus récent, Node.js 22.12 ou plus récent et pnpm 10.

Si tu utilises Homebrew, tu peux installer Go, Node.js et pnpm avec la commande suivante. Pour les outils Xcode, lance xcode-select --install si nécessaire.

brew install go node pnpm@10
export PATH="$(brew --prefix pnpm@10)/bin:$PATH"

Copie ces commandes dans le Terminal. Le script compile Pouple, l’installe dans ~/Applications et le lance. Si tu utilisais une autre copie, quitte-la avant de lancer le script.

Tu utilises NVM ? Après le clone, lance nvm install dans le dossier pouple-app avant le script. Si pnpm manque, lance npm install --global pnpm@10.

git clone https://github.com/Arthur-MONNET/pouple-app.git
cd pouple-app
bash scripts/install-local.sh

Pour mettre à jour, quitte Pouple et lance ces commandes depuis le dossier pouple-app.

git pull --ff-only
bash scripts/install-local.sh
